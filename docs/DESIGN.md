# 디자인 시스템 — 은우 북카드

**2026-08-17 개편.** 이 문서가 UI의 단일 진실 원천이다. `docs/SPEC.md` §8(초기 크림색 디자인)을 대체한다.
초기 디자인 원본 `design/영어책_학습카드_샘플.html`은 **구성 순서 참고용**으로만 남기고, 색·타이포는 이 문서를 따른다.

## 1. 방향

흰 종이 위에 시원한 파란색 하나로 길을 안내하는 학습 도구. 장식을 덜어내고 **글자 크기의 위계로 학습 동선을 만든다** — 아이가 볼 것은 크게, 부모가 참고할 것은 작게.

## 2. 색

기본은 흰색과 뉴트럴 그레이(살짝 푸른 기운), 포인트는 파랑 하나뿐이다. 다른 색조(노랑·초록·빨강)를 새로 도입하지 않는다.

```css
--bg:            #ffffff;  /* 페이지 배경 */
--surface:       #f7f9fc;  /* 섹션·박스 배경 */
--surface-2:     #eef2f7;  /* 표 헤더, 강한 구분 */
--line:          #e3e8ef;  /* 기본 경계선 */
--line-strong:   #cbd5e1;  /* 강조 경계선 */

--ink:           #0f172a;  /* 본문 (거의 검정) */
--ink-2:         #475569;  /* 보조 텍스트 */
--ink-3:         #94a3b8;  /* 캡션·비활성 */

--accent:        #0b72e7;  /* 시원한 파랑 — 포인트 (흰 배경 대비 4.6:1, AA) */
--accent-strong: #0857b0;  /* hover·active */
--accent-soft:   #e8f2fe;  /* 연한 파랑 배경 */
--accent-ink:    #06498f;  /* 파란 배경 위 텍스트 */

--danger:        #b3261e;  /* 삭제 확인에만 (파랑 체계 예외) */
```

**픽션/논픽션 구분**은 색조를 늘리지 않고 **같은 파랑의 명도 차이**로 한다 (SPEC §8의 꿀색은 폐기):

| 구분 | 강조색 | 용도 |
|------|--------|------|
| 논픽션 | `--accent` `#0b72e7` | 상단 바, STEP 배지, 유형 태그 |
| 픽션 | `--accent-deep` `#0e4c8a` | 동일 위치 (더 깊은 남색조 파랑) |

칩 라벨("픽션"/"논픽션")을 항상 함께 표시해 색만으로 구분하지 않는다(접근성).

## 3. 폰트

**G마켓 산스**를 self-host한다 (`public/fonts/*.woff2`, 서브셋 완료·한글 11,172자 전체 포함).
외부 CDN을 쓰지 않으므로 SPEC §8의 "외부 폰트·CDN 금지"(오프라인 인쇄 대비) 취지에 부합한다.

```css
@font-face {
  font-family: "GmarketSans";
  src: url("/fonts/GmarketSansLight.woff2") format("woff2");
  font-weight: 300; font-style: normal; font-display: swap;
}
/* Medium=500, Bold=700 동일 패턴 */
```

- 본문 스택: `"GmarketSans", -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", sans-serif`
- **영문 단어·예문에도 GmarketSans를 쓴다** (한 서체로 통일해 시각적 잡음을 줄인다)
- 굵기는 300(Light)·500(Medium)·700(Bold) 세 단계만 쓴다. 브라우저는 실제 사용하는 굵기만 내려받는다.

## 4. 타이포 스케일 — 학습 위계

크기는 장식이 아니라 **읽는 순서**다. 아이가 소리 내어 읽을 영어가 가장 크고, 부모용 참고 정보가 가장 작다.

| 역할 | 크기 / 굵기 | 색 | 비고 |
|------|-------------|-----|------|
| 책 제목(북헤더) | 28px / 700 (모바일 24) | ink | line-height 1.3 |
| 섹션 제목(STEP) | 18px / 700 | ink | 앞에 작은 배지 |
| **영단어(vocab word)** | **26px / 700** | ink | 카드에서 가장 큰 글자 |
| 단어 뜻(meaningKo) | 17px / 500 | ink | |
| 한글 발음(pronKo) | 15px / 500 | ink-2 | 단어 아래 |
| 영영 풀이(easyEn) | 14px / 300 | ink-2 | |
| 예문(exampleEn) | 15px / 300 | ink-2 | 대상 단어만 500 굵기로 강조 |
| **질문 영어(en)** | **20px / 500** | ink | 아이에게 읽어줄 문장 |
| 질문 한국어(ko) | 16px / 300 | ink-2 | |
| 부모 힌트(hintKo) | 13px / 300 | ink-3 | surface 배경 박스 |
| 줄거리·소개 본문 | 16px / 300 | ink | line-height 1.75 |
| 활동·미션 항목 | 16px / 300 | ink | |
| 메타 칩(AR·Lexile) | 12px / 500 | ink-2 | |
| 캡션·날짜 | 12px / 300 | ink-3 | |

- 한글 본문 line-height는 **1.7~1.75**, 큰 제목은 1.3.
- 글자 크기로 위계가 서므로 **밑줄·이탤릭·과한 색 강조를 쓰지 않는다.**

## 5. 형태

- 모서리: 카드 16px, 박스·버튼 12px, 칩 999px
- 그림자: 거의 쓰지 않는다. 필요하면 `0 1px 2px rgba(15,23,42,.06)` 한 단계만. 경계는 그림자가 아니라 `--line`으로.
- 여백: 8의 배수(8·12·16·24·32). 섹션 사이 24~32, 섹션 내부 12~16.
- 상단 컬러바: 카드 최상단 6px 실선(픽션/논픽션 색)
- 버튼: 주요 = accent 배경 + 흰 글자, 보조 = 흰 배경 + line 테두리 + ink 글자. 최소 높이 48px(모바일 터치).
- 표(단어장): 세로 줄 없이 가로 구분선만. 헤더는 surface-2 배경 + 12px ink-3.

## 6. 인쇄

- 배경은 흰색으로, 파란 포인트는 `print-color-adjust: exact`로 유지
- 인쇄 시 본문 스케일 약 90%로 축소하되 **영단어·질문 영어는 줄이지 않는다** (읽어주는 용도)
- 화면 전용 UI(내비·버튼·스피커·별점·관리 버튼) 숨김, 행·질문 카드 단위 `break-inside: avoid`

## 7. 적용 범위

홈 `/`, 카드 `/card/[id]`, 서재 `/library`, 잠금 `/unlock` **전 페이지에 동일 토큰을 적용한다.**
색·크기 값을 컴포넌트에 하드코딩하지 말고 CSS 변수(`app/globals.css`)로만 참조한다.
