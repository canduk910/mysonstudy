## 0. 목적과 성공 기준

사용자 요청(2026-10-09): `design/mom_english`의 자료로 **"엄마의 생활영어"**를 스트릭과 함께 만든다. 학습 지원은 기존 기능(복습·낭독·템플릿)을 재사용하고, **틀 → 예문 → 발화 체크·녹음·평가** 흐름. 1년에 걸쳐 부담 없이 분배하고, 난이도를 서서히 올린다(이후 반복).

학습자: 엄마 — **영어 말하기 입문자**(사용자 확정). 성인이지만 눈높이는 "처음 말해 보는 사람" — 한국어 설명을 두껍게, 용어는 쉽게, 판정은 너그럽게.

성공 기준:
- 첫 달 하루 **5~7분**으로 부담 없이 시작해, 1년 뒤 **18~20분**까지 자연스럽게 늘어난다.
- 매일 "오늘의 레슨" 하나를 끝내면 👩 🔥가 켜진다.
- 1년(1회차) 동안 말하기로 익히는 문장 약 900개, 다음 해(2회차) 반복으로 확장.

하지 않는 것(YAGNI): mp3 원음 재생(합성 음성으로 — 사용자 확정, 원음은 `docs/BACKLOG.md` 과제), 발음 점수, 자유 대화, 엄마 전용 AI 판독(사진 입력 없음).

## 1. 자료 분석(내용 비공개 — 구조만)

| 자료 | 성격 | 분량 | 쓰는 곳 |
|---|---|---|---|
| `soritune_speaking.md` | 스피킹 챌린지 10일 강의 전사 — "소리 블록"(시작·코어·디테일 블록) 방법론, 1~5일차 시작 블록, 6~10일차 코어 동사 블록 | 10강 | 0단계(오리엔테이션)의 블록·예문 소스. 한국어 설명은 **새로 쓴다**(강의 문장 인용 안 함) |
| mp3 100개(전사 `data/private/mom-english/transcripts/001~100.json`) | 파일 하나 = 소리 블록 하나: 핵심 문장 1 + 대화 4줄 + 확장 표현 5 + 스몰토크 3쌍. 영어만. 번호 순으로 난이도 상승(요청·의도 → 일상 묘사 → 접속·조건 → 관용 표현) | 블록 100, 약 1,500문장 | 1~4단계의 척추. 일부 파일은 첫 문장이 잘려 전사됨 → 가져오기 파일 만들 때 보정 |
| PDF 여권북 | 해외여행 상황 문장 — 5장(공항·기내 / 숙소 / 쇼핑 / 식당·카페 / 관광지) × 50, 영어+한국어 | 250문장, 대부분 5~7단어 | 1~3단계에 상황 응용으로 섞음(쉬워서 앞쪽) |

## 2. 1회차 범위 — 말하기 필수 / 듣기만 / 2회차

블록 하나:
- **말하기 필수(테스트 대상)**: 핵심 문장 1 + 확장 표현 5 = 6문장
- **듣고 따라 하기만(테스트 없음)**: 대화 4줄
- **2회차로**: 스몰토크 3쌍

PDF 문장은 전부 말하기 필수(짧음). md 블록은 블록당 대표 예문 3~5개를 말하기 필수로.

## 3. 1년 진도표(1회차) — 점진 증량

| 단계 | 주차 | 하루 | 하루 새 문장 | 자료 |
|---|---|---|---|---|
| 0 몸풀기 | 1~4 | 5~7분 | 2~3 | md 10강(블록 개념·기초 시작 블록·코어 동사 블록), 듣기·따라 하기 위주 |
| 1 부탁하고 원하기 | 5~16 | 8~10분 | 3~4 | mp3 1~15(주 1블록) + PDF 공항·기내, 식당·카페 약 100 |
| 2 일상 말하기 | 17~32 | 12~15분 | 4~5 | mp3 16~47(주 2블록) + PDF 쇼핑·숙소·관광지 약 100 |
| 3 길게 잇기 | 33~46 | 15~18분 | 5 | mp3 48~85(주 2~3블록) + PDF 남은 약 50 |
| 4 원어민 표현 | 47~52 | 18~20분 | 5~6 | mp3 86~100 — 목표: 알아듣기 + 핵심 문장 말하기 |

- 하루 시간은 **복습 포함**(간격 반복이라 쌓일수록 자연 증가).
- 주 구성: **월~목 새 레슨, 금 주간 테스트**. 토·일은 복습만(선택).
- **복습 주**: 8주마다 1주(새 문장 없음 — 복습·지난 테스트). 그만큼 4단계 끝이 1~2주 밀리면 다음 해로.
- **자동 감속**: 주간 테스트 정답률(맞음 비율)이 **2주 연속 60% 미만**이면 다음 주를 복습 주로 바꾼다.
- **진도는 완료 순서로**: "오늘의 레슨" = 아직 끝내지 않은 다음 레슨. 쉬어도 내용을 건너뛰지 않는다(🔥는 ①의 카드·만회 규칙을 따로 따른다).
- **2회차**: 같은 순서, 스몰토크 포함, 테스트를 "한국어 보고 바로 말하기"로, 0단계 1주.
- PDF 문장 배치: 장(상황)별로 묶고 장 안에서 단어 수 오름차순, 그 단계 블록과 틀이 겹치는 문장을 같은 주에 둔다(가져오기 파일 빌드 때 결정, 파일에 `week` 필드로 박음).

## 4. 하루 레슨

| 순서 | 내용 | 재사용 |
|---|---|---|
| ① 오늘의 틀(30초) | 틀 카드 — 틀 모양 + 빈자리 강조 + "이럴 때 써요" 한국어 설명 | 토익 틀 카드 렌더(빈자리 강조) |
| ② 소리 듣기(1분) | 핵심 문장을 **소리 블록 단위로 끊어** 합성 음성으로. 덩어리 사이 쉼, 0.8배속 시작 | `speakQueue` + 조각 뒤 쉼 + 읽기 속도 |
| ③ 따라 말하기(2분) | 한국어 1번 → 영어 N번(N = 단계별 3→2), 녹음 없음 | 토익 템플릿 따라 말하기 대본 생성 |
| ④ 발화 체크(2분) | 말하기 필수 문장마다 🎤 → 받아쓰기 → 비교 → ✓/다시. 막히면 첫 단어 → 블록 덩어리 → 정답 듣기 | 관문 T 받아쓰기·틀 비교 함수·힌트 사다리 |
| ⑤ 대화 듣기(선택) | 대화 4줄 듣고 따라 하기 | `speakQueue` |
| 끝 | 레슨 기록 저장 → 🔥, 말하기 필수 문장을 복습 목록(`mom` 영역)에 등록 | 오늘의 복습 |

- 0단계는 ④를 2문장으로 줄이고 ③ 비중을 키운다.
- 한 판(① 스펙 §2) = **④까지 끝낸 레슨**(`finishedAt` + 말하기 필수 문장 전부 시도 — ✓든 "넘어가기"든 결과가 있음).

### 4-1. 발화 판정(너그럽게, AI 없음)
- 받아쓰기는 기존 관문(영어, 프롬프트에 정답을 넣지 않음 — 받아쓰기 무유도 원칙).
- **✓ 통과**: 틀(핵심 블록 — 가져오기 파일의 `frame` 낱말들)이 순서대로 들어 있고, 내용 낱말(관사·전치사 제외)의 70% 이상 일치.
- **아깝다**: 틀은 맞고 내용 낱말 40~70%, 또는 내용은 맞는데 틀 일부 누락.
- **다시**: 그 밖. 무응답(말 시작 없음·전사 2낱말 미만)은 "다시".
- 관사·시제·복수형 차이는 감점 없이 "이렇게도 말해요" 한 줄.
- 정확한 비교 규칙은 토익 틀 비교 함수(편집 거리·축약형 정규화)를 재사용하고 임계값만 엄마용 상수로 둔다.

## 5. 주간 테스트(금)

- 문항: 이번 주 말하기 필수 문장 중 **0~1단계 5개 → 2단계 8개 → 3~4단계 10개**(정답률 낮던 문장 우선, 나머지 무작위·결정적 시드).
- 한국어만 보여 주고 말하기 → 녹음(기기 IndexedDB에만, 토익 응시와 같은 방식) → 받아쓰기 → §4-1 판정.
- 결과: 문항별 맞음/아깝다/다시 + **내 녹음 ▶ / 원어민(합성) ▶** 비교.
- **AI 총평(호출 M1)**: 테스트당 1회 — 한국어 1~2줄(잘한 점 1, 고칠 점 1). 입력은 문항별 (한국어 뜻, 목표 문장, 받아쓰기, 판정)만, 녹음 없음. 실패하면 총평 없이 결과 저장(테스트 자체는 AI와 무관).
- 틀린 문장 → 복습 목록 맨 앞(오답 우선).
- 주간 테스트 완료도 그날의 한 판.

## 6. 데이터

### 6-1. 가져오기 파일 `mom-english/v1` (`data/private/mom-english-v1.json`)
```
{ format: "mom-english/v1", presetKey: string,
  blocks: [{ id: "md-01"|"mp3-001"|"pdf-ch1-01"…, source: "md"|"mp3"|"pdf", no: number, stage: 0..4, week: 1..52,
             frame: { text: string, slots: string[] }, explainKo: string,
             sentences: [{ id, role: "core"|"expand"|"dialog"|"smalltalk"|"situation", en, ko, chunks: string[] }] }] }
```
- `chunks` = 소리 블록 끊는 위치(합치면 `en`과 같아야 — zod 검증).
- `explainKo`는 새로 쓴 설명(강의 문장 인용 금지).
- 만드는 법: Claude가 자료를 정리해 빌드 스크립트(저장소 밖 scratch)로 생성 — mp3·md 문장의 **한국어 뜻·끊는 위치는 AI로 한 번**(텍스트 모델, 약 1,300문장 — 사용자 동의 2026-10-09), PDF는 원문 한국어 사용·끊는 위치만 AI. 결과는 Claude가 표본 검수 후 보정.
- 앱 "파일로 가져오기": `presetKey` 멱등(같은 파일 재반입 = 덮어쓰기, 진도·기록 유지).

### 6-2. 저장(새 컬렉션)
| 컬렉션 | 내용 |
|---|---|
| `momContent` | 가져온 블록(블록당 문서) |
| `momLessons` | 레슨 기록 `{id, blockId, kind: "lesson"|"review-week", startedAt, finishedAt, checks: [{sentenceId, verdict, transcript, hintLevel}]}` |
| `momTests` | 주간 테스트 `{id, week, startedAt, finishedAt, items: [{sentenceId, verdict, transcript, recorded}], summaryKo: string|null}` |

### 6-3. 진도 엔진(순수, `lib/mom-plan.ts`)
- 입력: 블록 목록·레슨 기록·테스트 기록·오늘(KST) → 출력: 현재 주차·단계, 오늘의 레슨(또는 테스트·복습 주), 감속 여부, 진도 지도.
- 레슨 순서 = (week, 요일 슬롯, 블록 no) 정렬; 완료한 레슨은 건너뜀.

## 9. 검증

- `eval:mom`(오프라인): 진도 엔진(단계 경계·복습 주·감속·완료 순서), 판정(§4-1 경계값), 가져오기 zod(chunks 조인·필수 필드), 한 판 판정, 스트릭 통합(eval:streak에 엄마 트랙 항목).
- 실호출: 동의 뒤 M1 1회, 받아쓰기는 레슨 화면 실사용으로.
- 실기기(엄마 폰): 마이크 권한·녹음·합성 음성 재생·홈 화면 앱·알림.
- 교재 문장 유출 스캔: 커밋 전 전사·PDF 문장으로 추적 파일 grep.

## 11. 위험

- 전사 품질(잘린 첫 문장·오인식) → 빌드 때 보정·표본 검수, 이상 문장은 `role: "dialog"`(듣기만)로 강등.
- 입문자에게 발화 체크 실패가 잦으면 의욕 저하 → 판정 너그럽게 + "넘어가기"도 한 판에 포함 + 자동 감속.
- 합성 음성의 연음이 원어민과 다름 → 소리 블록 끊어 읽기로 보완, 원음은 과제.
- 저작권 — 가져오기 파일·전사본은 git 밖, 리포트에 문장 금지.
