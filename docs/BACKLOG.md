# 과제 목록 (BACKLOG)

아직 만들지 않았지만 만들 가치가 있다고 판단한 기능을 적어 둔다. 여기 있는 항목은 **바로 만들지 않는다** — 관련 기능을 쓰는 모습(복습 기록·시험 결과·사용자 신고)을 보고, 적기라고 판단될 때 오케스트레이터가 사용자에게 **진행 여부를 제안**한다. 진행하기로 하면 이 문서에서 지우고 해당 스펙 문서로 옮긴다.

### 진행할 때 지킬 것

- ①의 복습 큐(SPEC §23)와 **같은 일정 저장을 쓴다** — 새 기능의 결과도 복습 어댑터로 넘겨 간격 반복에 들어가게 한다.
- 모드를 분리한다 — 새 시험 모드의 숙련도를 기존 모드와 섞지 않는다(일본어·토익·은우 공통 원칙).
- 토익은 틀(템플릿) 반복 중심, 교재 원문은 저장소 밖(`data/private/`) — 기존 원칙 그대로.
