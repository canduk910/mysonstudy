# 엄마의 생활영어 — AI 하네스 스펙 (subject `mom`)

> 2026-10-09 신설. 제품 흐름은 `docs/SPEC.md` §24, 설계 원본은 `docs/superpowers/specs/2026-10-09-mom-english-design.md`(끝의 "구현 동기화" 절이 구현과 달라진 점), 과목 공통 규약은 `docs/HARNESS.md`.
> **저작권**: 이 문서·코드·eval·리포트에는 교재·강의·음원의 문장을 옮기지 않는다. 아래 예시 문장은 전부 지어낸 것이다. 자료는 `data/private/`(git 밖)에만 있고 앱에는 "파일로 가져오기"로만 들어간다(§6).

## 0. 학습자·눈높이

- 학습자는 **엄마 — 영어 말하기 입문 성인**. 은우(초등)와도, 아빠(JLPT·토익스피킹 수험자)와도 다르다 — 성인이지만 "처음 말해 보는 사람".
- 한국어 설명을 두껍게, 용어는 쉬운 말로(관사·시제 같은 문법 용어를 쓰지 않는다), 판정은 너그럽게(§3).
- 하루 부담: 0단계 5~7분 → 4단계 18~20분(`momMinutesHint` — 복습 포함 어림).

## 1. 호출 표

| 호출 | 하는 일 | 모델 | 진입 함수 | 게이트 |
|---|---|---|---|---|
| **M1** 주간 테스트 총평 | 문항별 (한국어 뜻, 목표 문장, 받아쓰기, 판정) → 한국어 두 줄(잘한 점 `goodKo` · 고칠 점 `fixKo`) | 기본 텍스트 모델(`resolveModel()` — `OPENAI_MODEL`, 빈 값이면 `gpt-6-luna`) | `lib/ai/mom/calls.ts` `summarizeMomTest` | `EVAL_MOM=1` 1회 |

- **받아쓰기는 새 호출이 아니다** — 토익 관문 T(`lib/toeic-transcribe.ts` `transcribeAnswer`)를 그대로 쓴다(라우트 `POST /api/mom/transcribe`). 기대 문장·틀을 받지도 보내지도 않는다(받아쓰기 무유도). 새 env 없음.
- 레슨 판정·진도·대본·힌트는 전부 **AI 없는 순수 함수**다(§3·§4).
- 파일 배치: `lib/ai/mom/{prompts,schemas,calls}.ts`(프롬프트·스키마는 클라이언트 안전, `calls.ts`는 서버 전용) · 순수 모듈 `lib/mom-{content,contract,plan,judge,lesson-script}.ts` · eval `scripts/eval-mom.ts`(`npm run eval:mom`).

## 2. 호출 M1 — 주간 테스트 총평

### 2-1. 시스템 프롬프트 (`MOM_SUMMARY_SYSTEM_PROMPT` — 원문 그대로, spec-sync 대상)

```text
너는 영어 말하기를 처음 배우는 성인(엄마)의 다정한 코치다. 이번 주 말하기 테스트 결과를 보고 한국어로 짧게 말해 준다.
- goodKo: 잘한 점 하나(구체적으로 — 어떤 문장·틀을 잘 말했는지). 1문장, 60자 안팎.
- fixKo: 다음 주에 고칠 점 하나(가장 자주 틀린 틀이나 소리 하나만, 쉬운 말로). 1문장, 60자 안팎.
- 영어 용어(관사·시제 등)는 쓰지 말고 쉬운 한국어로. 점수·등급·비교는 말하지 않는다.
- 받아쓰기는 기계가 받아 적은 것이라 틀릴 수 있다 — 발음을 단정하지 말고 "이렇게 들렸어요" 수준으로만.
- 영어 문장을 인용할 때는 입력에 있는 목표 문장만 그대로 쓴다.
```

### 2-2. 사용자 메시지 (`buildMomSummaryUserMessage`)

문항마다 한 줄 — `- 뜻: {ko} / 목표: {en} / 받아쓰기: {transcript, 없으면 "없음"} / 판정: {맞음|아깝다|다시|넘어감}`. 각 칸의 줄바꿈·연속 공백은 한 칸으로 접는다(한 문항이 한 줄). **녹음은 보내지 않는다.** 예(지어낸 것): `- 뜻: 창가 자리로 주세요. / 목표: A window seat, please. / 받아쓰기: a window sit please / 판정: 아깝다`.

### 2-3. JSON Schema (`MOM_SUMMARY_JSON_SCHEMA` — 의미 동치 대조)

```json
{
  "name": "mom_summary",
  "strict": true,
  "schema": {
    "type": "object",
    "additionalProperties": false,
    "required": ["goodKo", "fixKo"],
    "properties": {
      "goodKo": { "type": "string" },
      "fixKo": { "type": "string" }
    }
  }
}
```

### 2-4. zod·호출 옵션·실패

- zod `momSummaryZod`: 두 필드 모두 trim 뒤 **1~120자**, 한글(`[가-힣]`)이 한 글자 이상, 추가 필드 거부(`.strict()`). 어기면 `callWithSchema`의 재요청 규약(HARNESS §2)을 따른다.
- 호출 옵션: temperature 0.4, maxOutputTokens 400, call 라벨 `mom_summary`.
- 라우트 `POST /api/mom/tests/{id}/summary` 순서: ① 테스트 없음 404 ② **이미 저장된 `summaryKo`가 있으면 그대로 200**(키 없이도 — 재전송은 호출 0회) ③ 키 없음 501 ④ 블록에서 문항 문장 조회(못 찾으면 422) → `summarizeMomTest`(요청 신호 + 45초 상한) → `setMomTestSummary` → 200 / 실패 500. 이 순서는 eval이 주석을 뺀 소스의 위치로 잠근다.
- **총평이 실패해도 테스트 기록은 그대로다**(테스트 자체는 AI와 무관 — 결과 화면에서 총평 줄만 숨는다).

## 3. 발화 판정 규칙 (`lib/mom-judge.ts` `judgeMomSpeech` — AI 없음)

입력 `{ en(목표 문장), frameText(블록 틀 글자), transcript(받아쓰기) }` → `pass`(맞음) · `close`(아깝다) · `retry`(다시). 낱말 정규화·축약형·빗금 대안 펼치기는 토익 틀 함수(`lib/toeic-template.ts`)를 재사용한다.

| 상수 | 값 | 뜻 |
|---|---|---|
| `MOM_PASS_CONTENT` | 0.7 | 틀이 맞고 내용 낱말 일치 비율이 이 이상이면 맞음 |
| `MOM_CLOSE_CONTENT` | 0.4 | 틀이 맞고 이 이상이면 아깝다(틀이 빠졌어도 내용 0.7 이상이면 아깝다) |
| `MOM_FUNCTION_WORDS` | a·an·the·to·of·in·on·at·for·with·and·is·are·am·be | 내용 낱말에서 뺀다 — 빠지거나 바뀌어도 감점 없음 |
| `MOM_FILLER_WORDS` | um·uh·er·ah·oh·please·okay·ok·yes·no·sure·well·so·hmm·right | 군말 — 덧붙여도 감점 없음 |

- **무응답**: 받아쓰기 2낱말 미만 → `retry` + `noSpeech`.
- **틀 검사**: 틀 글자의 `~`·`…` 자리 표시를 빼고, 빗금 대안은 낱말 단위(토익 함수) + 구절 단위(`What time/When ~?` — 오른쪽 대안이 앞 구절 전체를 바꿈)로 펼친다. 목표 문장에 순서대로 들어 있는 대안만 검사하고(짧은 대안이 긴 대안의 부분이면 뺀다), 그중 하나가 들은 말에 순서대로 있으면 통과. **안전장치**: 어느 대안도 목표 문장에 맞지 않으면(길이가 고르지 않은 빗금 등) 목표 문장 낱말 중 틀 글자에 있는 것을 순서대로 요구한다 — 틀 검사를 조용히 끄지 않는다. 검사할 낱말이 하나도 없을 때만 기본 통과.
- **너그러운 같음**: 복수 `-s`, `-ed`·`-ing`(남는 줄기 3글자 이상), `-d` 하나는 `-ed`로 끝나고 뗀 줄기가 `e`(ee 아님)로 끝날 때만(liked→like, need는 그대로). 떼어 낸 결과가 대명사·기능어(he·she·we·me·be·so·no·do·go 등 + 기능어 표)면 떼지 않는다(shed→she 오인 방지). 자주 쓰는 불규칙 활용 표(go·went·gone 등 21줄)는 같은 줄끼리 같다 — **시제 감점 없음**.
- **덧붙임 감점**: 목표에 없는 내용 낱말(기능어·군말·틀 낱말 제외) 수 × 2 ≥ 목표 내용 낱말 수면 맞음을 아깝다로 낮춘다(다른 말에 목표 낱말이 우연히 섞인 경우).
- 맞음인데 들은 말이 목표와 낱말 단위로 같지 않으면 `noteKo` = "이렇게도 말해요: {목표 문장}".

## 4. 진도 엔진 규칙 (`lib/mom-plan.ts` — 순수·결정적)

- **진도는 달력이 아니라 완료 순서**. 같은 입력 = 같은 출력(시각·난수 없음). "오늘의 레슨" = 아직 끝내지 않은 다음 레슨.
- 단계 `momStageOfWeek`: 1~4주 0 · 5~16주 1 · 17~32주 2 · 33~46주 3 · 47~52주 4. 테스트 문항 수 `momTestSize` 5·5·8·10·10. 따라 말하기 반복 `momShadowRepeat` 3·3·3·2·2.
- **레슨** = 그 주 블록들의 말하기 문장(역할 core·expand·situation)을 블록 순서대로 이어 `MOM_LESSONS_PER_WEEK`(4)등분한 묶음(`w{주}-d{1..4}`, 빈 묶음은 만들지 않음). 듣기 = 그 레슨 문장이 나온 모든 블록의 대화(dialog) 문장. smalltalk는 1회차에서 쓰지 않는다.
- **한 레슨 완료**(`isFullMomLesson`) = `finishedAt` 있고 그 레슨 말하기 문장 전부에 결과가 있음(✓·아깝다·다시·넘어감 모두 결과).
- **주간 테스트**는 요일이 아니라 **그 주 레슨을 다 끝낸 다음 차례**에 열린다. 문항(`momPickTestItems`) = 그 주 풀에서 레슨 때 다시·아깝다였던 문장 먼저, 나머지는 주 번호 시드의 결정적 순서. 완료 = `finishedAt` + 문항 ≥ 1 모두 판정 있음.
- **복습 주** `MOM_REVIEW_WEEKS` = 8·16·24·32·40·48(블록 없는 주) — 직전 8주 말하기 문장에서 결정적으로 레슨 4개 × 5문장(`rw{주}-d{n}`).
- **자동 감속**: 새 주 N에 들어가기 직전, 마지막 복습 주 이후 걸어온 새 주 중 최근 두 주의 완료 테스트 맞음 비율이 둘 다 `MOM_SLOWDOWN_THRESHOLD`(0.6) 미만이면 N 앞에 **가상 복습 주 N+100**(`MOM_VIRTUAL_WEEK_OFFSET`)을 끼운다. 복습 주(실제·가상)를 걸으면 비율 창을 비운다 — 다음 주가 이미 실제 복습 주면 그것으로 충족, 낮은 한 쌍은 복습 주를 많아야 하나 부른다. 화면은 가상 주를 "복습 주"로 보이고, 진도 지도는 원래 주 N을 현재로 보인다. 테스트 라우트는 주 1~52와 101~152를 받는다.
- 하루 분량 상한(가져오기 파일을 만들 때 정함 — 엔진이 아니라 자료): 단계 0·1·2·3·4 = 하루 새 말하기 문장 3·4·5·5·6. 넘치는 md 예문은 듣기 전용(dialog)으로, 자리가 없는 PDF 문장은 2회차(smalltalk, 52주)로 미뤘다.

## 5. eval (`npm run eval:mom`)

- **기본 오프라인(무비용)** — 네트워크를 막고(`fetch`가 던짐) 지어낸 픽스처로 돈다. 2026-10-09 기준 **85항목**: 가져오기 계약 7 · 가져오기 결정 4 · 저장 계약 4 · 진도 엔진 20 · 발화 판정 25 · 배선 2 · 레슨 6 · 테스트·총평 12(총평 라우트 순서 — 주석을 뺀 코드에서 not_found < 저장된 총평 재사용 < 키 검사 < `summarizeMomTest(` < `setMomTestSummary(` — 와 토익 녹음 보호 정적 점검 6: 엄마 풀은 `"gone"`으로 저장, 토익 업로드 대기열·"내 녹음" 목록에서 제외, 메모리 폴백도 풀끼리 서로 비우지 않음) · spec-sync 5.
- **spec-sync**: `MOM_SUMMARY_SYSTEM_PROMPT`가 이 문서 §2-1 코드블록과 바이트 대조(block-exact), `MOM_SUMMARY_JSON_SCHEMA`가 §2-3과 의미 동치, 호출 옵션이 §2-4 문장과 같음, 판정 상수(0.7·0.4)가 §3 표와 같음.
- **실호출 게이트**: `EVAL_MOM=1`이고 `EVAL_OFFLINE_ONLY`가 없을 때만 지어낸 5문항으로 `summarizeMomTest` **1회**(재요청 시 +1) → zod 통과·두 줄 모두 한글. 비용이 드는 검증이라 **사용자 동의 후 오케스트레이터가** 실행한다.

## 6. 저작권·자료 위치

- 원자료(강의 전사·음원 전사·여권 문장 PDF)는 `design/mom_english/`·`data/private/`(둘 다 gitignore)에만 있다. 앱 반입 파일은 `data/private/mom-english-v1.json`(형식 `mom-english/v1`, `presetKey` 멱등 — 같은 파일 재반입 = 내용 바뀐 블록만 갱신, 진도·기록 유지, 파일에 없는 블록은 지우지 않음).
- 프로덕션 반입은 엄마(또는 가족)가 앱 `/mom`의 "파일로 가져오기"로 한다 — 로컬 스크립트가 프로덕션 DB에 쓰지 않는다.
- **금지**: 교재·강의·음원 문장을 코드·eval 픽스처·문서·리포트·커밋 메시지·주소 쿼리에 옮기기. 예시는 새로 지어낸다. 블록의 `explainKo`는 새로 쓴 설명이다(강의 문장 인용 아님).
- 커밋 전 교재 문장 유출 스캔(가져오기 파일의 영어 문장 전부를 추적 파일에서 고정 문자열 검색 → 0건)을 오케스트레이터가 한다.
